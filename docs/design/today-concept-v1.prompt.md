# Today concept v1 generation prompt

Mode: built-in image generation
Use case: `ui-mockup`

```text
Create a polished side-by-side comparison of the same Luqa Today mobile screen
in light mode and dark mode. Luqa is a private personal operating system for
time tracking, habits, sleep, gym, money, reports, and life reflection.

Show two full portrait Android phone screens side by side on a plain neutral
studio backdrop with no hands or perspective distortion. Use a high-fidelity
native mobile UI style with bold editorial hierarchy, stark black and white,
precise modern grotesk typography, and a subtly technical but personal mood.
The result should have confident mobile-banking-level restraint without copying
an existing product.

Each screen contains a large Today title, Wednesday 27 August, one dominant
active timer for Writing thesis at 01:42:18 with a decisive Stop action, a 7h
17m sleep row, compact colored Water, Read, and Stretch habit controls, a
continuous vertical timeline with Breakfast, Thesis, and Gym entries, and a
five-destination bottom navigation for Today, Habits, Gym, Money, and Insights.

Light colors: #FBFBFA, #FFFFFF, #1A1A1E, #6543E8. Dark colors: #0B0B0D,
#141417, #F4F4F5, #A78BFA. Use restrained data colors for identity. Use crisp
6-12 px corner radii, continuous surfaces, and precise dividers. Keep one focal
point per screen. Use maximum-contrast black/white for the primary action and
purple for focus and active state.

Avoid Trade Republic branding or literal screen copying, financial charts,
gradients, glow, glassmorphism, neon cyberpunk, huge shadows, cream paper,
excessive rounded cards, childish gamification, mascots, confetti, generic
dashboard grids, iOS chrome, illegible text, and watermarks.
```
